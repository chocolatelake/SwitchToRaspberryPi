# Raspberry Pi Pico Switchコントローラー化 セットアップ手順

PC(C# GUI)からRaspberry Pi Picoへシリアル通信でコマンドを送り、PicoをNintendo Switchのコントローラー（POKKEN CONTROLLER互換）として動作させるための環境構築手順です。

## 1. 前提条件（トラブルシューティング）
- **Windowsのユーザー名が半角英数字のみ**であること。
  （※ユーザー名に日本語が含まれていると、Arduino IDEのコンパイル時に文字化けによるエラー `boot2.o: No such file or directory` が発生し、書き込みができません）
- データ通信可能なUSBケーブルを使用すること。

## 2. Arduino IDE の準備
1. Arduino公式サイトからArduino IDEをダウンロードしてインストールします。
2. Arduino IDEを起動します。

## 3. Raspberry Pi Pico 用のボードデータを追加する
公式のMbed版ではなく、より高機能な有志版（Earle F. Philhower版）を使用します。

1. **ボードマネージャのURLを追加**
   - 上部メニューから **「ファイル」 > 「基本設定」** を開きます。
   - **「追加のボードマネージャのURL」** に以下を入力し「OK」を押します。
     `https://github.com/earlephilhower/arduino-pico/releases/download/global/package_rp2040_index.json`
2. **ボードデータのインストール**
   - 左側の基板アイコン（ボードマネージャ）をクリック、または **「ツール」 > 「ボード」 > 「ボードマネージャ」** を開きます。
   - 検索窓に `pico` と入力します。
   - **「Raspberry Pi Pico/RP2040 by Earle F. Philhower, III」** を探し、**「インストール」** をクリックします。

## 4. ボードとUSB Stackの設定（超重要）
1. 上部メニューから **「ツール」 > 「ボード」 > 「Raspberry Pi Pico/RP2040」** の中から、**「Raspberry Pi Pico」** を選択します。
2. **「ツール」 > 「USB Stack」** を **「Adafruit TinyUSB」** に設定します。

*※注意: このボードデータにはSwitch化に最適な「Adafruit TinyUSB」ライブラリが最初から内蔵されています。ライブラリマネージャから個別に「Adafruit TinyUSB Library」をインストールする必要はありません。（重複エラーの原因になります）*

## 5. プログラム（ソースコード）の準備
`switch_ctrl.ino` を開きます。以前のコードから以下の点を修正しているか確認してください。

**【1. 通信方式の修正】**
PCからのUSBシリアル通信を受け取るため、ハードウェアシリアル用の `Serial1` ではなく、USB用の **`Serial`** を使用します。
- `Serial1.begin(9600);` → `Serial.begin(9600);`
- `Serial1.available()` → `Serial.available()`
- `Serial1.read()` → `Serial.read()`

**【2. USBデバイス設定の修正】**
使用するオブジェクト名は、`USBDevice` ではなく **`TinyUSBDevice`** を使用します。
```cpp
TinyUSBDevice.setID(0x0F0D, 0x0092);
TinyUSBDevice.setProductDescriptor("POKKEN CONTROLLER");
TinyUSBDevice.setManufacturerDescriptor("HORI CO.,LTD.");
```

## 6. マイコンへの書き込み
マイコンが見つからないエラー（`No drive to deploy.`）が出る場合や、確実に書き込みたい場合は以下の手順で行います。

1. **BOOTSELモードでPCに接続**
   - Raspberry Pi Pico のUSBケーブルを一度PCから抜きます。
   - Pico基板上の **「BOOTSEL」という白いボタンを押したまま**、PCにUSBケーブルを接続します。
   - PCに「RPI-RP2」というUSBメモリのようなドライブとして認識されたら、ボタンから指を離します。
2. **書き込み**
   - Arduino IDEの左上にある **「→（書き込み）」** ボタンをクリックします。
   - 黒いコンソール画面に `Flashing D: (RPI-RP2)` や `Done uploading` と表示されれば成功です。

## 7. C# (PC側) プログラム実行時の注意点
書き込みが完了すると、マイコンは「POKKEN CONTROLLER」としてPCに再認識されます。
この際、割り当てられるCOMポート番号が書き込み前と変わることがあります。

1. Windowsのスタートボタンを右クリックし、「デバイスマネージャー」を開きます。
2. 「ポート (COM と LPT)」ツリーを開き、認識されたUSBシリアルデバイスの新しいCOMポート番号（例：COM3など）を確認します。
3. C#側のソースコード内で指定しているCOMポート番号を、新しく確認した番号に書き換えてからGUIアプリを実行してください。
